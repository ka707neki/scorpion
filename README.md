# 🦂 Scorpion Cursor – Luxury Edition

A Python + Pygame project where a stylish, procedurally animated scorpion follows your mouse cursor. It has a 90-joint segmented body, stepping legs, glowing claws, a curled stinger, a particle trail, and a dark-gold "luxury" color theme.

## Features

- Smooth head movement toward the mouse with easing and a dead zone
- Snake-like body: every joint follows the previous one at a fixed distance
- Four pairs of legs that stay planted and take a step only when the body drifts away
- Claws that glow while the scorpion moves
- Curled tail whose stinger gently "breathes" (sine-wave animation)
- Particle trail with gravity and fade-out
- Shadow / main / highlight layering for a metallic 3D look
- Subtle background grid and a live FPS counter

## Requirements

- Python 3.8+
- [Pygame](https://www.pygame.org/)

```bash
pip install pygame
```

```bash
python scorpion_cursor.py
```

| Input | Action |
|-------|--------|
| Mouse move | The scorpion follows the cursor |
| `ESC` | Quit |
| Window close button | Quit |

## How it works

- **Body chain:** the head moves toward the mouse, and each next joint is pulled to stay exactly `D` pixels from the one before it.
- **Local frames:** for every joint a tangent (body direction) and a normal (90° sideways) are computed and reused for legs, ribs and claws.
- **Legs:** each foot stays planted until it is more than 42 px from its ideal position, then glides to it. The knee is placed between hip and foot and pushed outward.
- **Tail:** points are generated by repeatedly rotating a direction vector by a growing angle, producing a curl.
- **Stinger:** a thin triangle built from the tail direction and its perpendicular vector.
- **Particles:** each particle has a lifetime that controls its size and brightness, and gravity pulls it down.

## Customization

Edit these values at the top of the file:

| Setting | Effect |
|---------|--------|
| `W`, `H` | Window size |
| `N`, `D` | Number of body joints and spacing (body length) |
| `FPS` | Frame rate cap |
| `HEAD_SPEED`, `SPEED_MULTIPLIER` | How fast the scorpion chases the mouse |
| `FOOT_SMOOTH` | How quickly feet snap to new positions |
| `COLORS` | The whole color theme |
